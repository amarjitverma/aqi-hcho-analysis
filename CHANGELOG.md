# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-15

### Added
- Initial project structure
- Data acquisition modules (Sentinel-5P, ERA5, FIRMS, CPCB, OpenAQ)
- Preprocessing pipeline (cleaning, alignment, gap-filling, feature engineering)
- GIS utilities (projections, grid, raster, vector, interpolation, masking)
- Deep learning models (LSTM, CNN-LSTM, ConvLSTM, Transformer, Ensemble)
- Training framework (trainer, callbacks, losses, schedulers)
- Evaluation module (metrics, evaluator, visualizer)
- Analysis modules (hotspot detection, correlation, transport, source attribution)
- Visualization utilities (maps, charts, dashboard utils)
- Pipelines (training, inference, evaluation)
- Optimization (Optuna hyperparameter search)
- Validation (cross, spatial, temporal, uncertainty)
- Inference (predictor, postprocessing)
- Streamlit dashboard (Map View, Model Performance, Biomass Burning)
- Configuration files (YAML)
- Documentation (architecture, methodology, data pipeline, models, user guide)
- Unit tests (data, models, analysis, GIS)
- Scripts (download, preprocess, train, predict, dashboard, generate_report)
- Docker support
- CI/CD workflow
- Pre-commit hooks
